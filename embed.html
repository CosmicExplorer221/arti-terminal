🖥️ ARTI Terminal - Embedding Guide

This page demonstrates different ways to embed the ARTI terminal component on your website.

⚠️ Security Note: Never expose API keys in client-side code. Use server-side proxies or build-time environment variable injection for production deployments.

Method 1: Direct Script Include

The simplest way to embed the terminal is to include all necessary scripts directly in your HTML:

<!-- Include JetBrains Mono font -->
<link href="https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;500;700&display=swap" rel="stylesheet">

<!-- Include terminal styles -->
<link rel="stylesheet" href="https://yourdomain.com/terminal.css">

<!-- Terminal container -->
<div id="arti-terminal"></div>

<!-- Include scripts -->
<script src="https://yourdomain.com/config.js"></script>
<script src="https://yourdomain.com/slack-logger.js"></script>
<script src="https://yourdomain.com/ai-handler.js"></script>
<script src="https://yourdomain.com/terminal.js"></script>

<!-- Initialize terminal -->
<script>
  // Set environment variables (use your build system to inject these securely)
  window.GEMINI_API_KEY = 'YOUR_API_KEY';
  window.SLACK_WEBHOOK_URL = 'YOUR_WEBHOOK_URL';

  // Initialize
  const slackLogger = new SlackLogger(window.SLACK_WEBHOOK_URL, CONFIG.slack);
  const aiHandler = new GeminiAIHandler(window.GEMINI_API_KEY, CONFIG.ai.systemPrompt);
  const terminal = new ArtiTerminal('arti-terminal', CONFIG, slackLogger, aiHandler);
</script>

Method 2: iframe Embed

For complete isolation and easier deployment, use an iframe:

<iframe
  src="https://yourdomain.com/terminal/"
  width="100%"
  height="700px"
  frameborder="0"
  style="border: none; border-radius: 8px; box-shadow: 0 10px 50px rgba(0,0,0,0.3);"
  title="ARTI Terminal Console"
  allow="clipboard-write"
></iframe>
Benefits of iframe:
  • Complete style isolation (no CSS conflicts)
  • Easier to update (change iframe src)
  • Better security separation
  • Can be embedded on any website

Method 3: As NPM Package

For React/Vue/Angular applications, you can package this as a module:

// Install package
npm install arti-terminal

// Import in your React app
import ArtiTerminal from 'arti-terminal';
import 'arti-terminal/dist/terminal.css';

function App() {
  return (
    <div className="App">
      <ArtiTerminal
        geminiApiKey={process.env.REACT_APP_GEMINI_API_KEY}
        slackWebhookUrl={process.env.REACT_APP_SLACK_WEBHOOK_URL}
      />
    </div>
  );
}
Note: NPM package distribution requires additional bundling setup (webpack/rollup). See README for details.

Method 4: Single Bundle via CDN

Create a single bundled JavaScript file for easy CDN hosting:

<!-- Single bundle include -->
<link href="https://cdn.yourdomain.com/arti-terminal/latest/terminal.min.css" rel="stylesheet">
<script src="https://cdn.yourdomain.com/arti-terminal/latest/terminal.min.js"></script>

<!-- Initialize -->
<div id="arti-terminal"></div>
<script>
  ArtiTerminal.init({
    containerId: 'arti-terminal',
    geminiApiKey: 'YOUR_API_KEY',
    slackWebhookUrl: 'YOUR_WEBHOOK_URL',
  });
</script>
Build Required: This method requires bundling all files into a single minified JavaScript file using webpack, rollup, or similar.

Method 5: WordPress Shortcode

For WordPress sites, you can create a shortcode:

// In your theme's functions.php or custom plugin
function arti_terminal_shortcode($atts) {
    $atts = shortcode_atts(array(
        'height' => '600px',
    ), $atts);

    wp_enqueue_style('arti-terminal', get_template_directory_uri() . '/terminal.css');
    wp_enqueue_script('arti-config', get_template_directory_uri() . '/config.js', array(), '1.0', true);
    wp_enqueue_script('arti-slack', get_template_directory_uri() . '/slack-logger.js', array(), '1.0', true);
    wp_enqueue_script('arti-ai', get_template_directory_uri() . '/ai-handler.js', array(), '1.0', true);
    wp_enqueue_script('arti-terminal', get_template_directory_uri() . '/terminal.js', array(), '1.0', true);

    return '<div id="arti-terminal" style="height: ' . esc_attr($atts['height']) . '"></div>';
}
add_shortcode('arti_terminal', 'arti_terminal_shortcode');

// Usage in posts/pages:
[arti_terminal height="700px"]

Configuration & Deployment Tips

Environment Variables

  • Vercel: Add env vars in project settings, access via process.env.GEMINI_API_KEY
  • Netlify: Add in Build & Deploy settings, inject via _redirects or build script
  • Cloudflare Pages: Set in Workers & Pages settings, access in Functions
  • Custom Server: Use server-side templating to inject variables

Security Best Practices

  • Never commit .env file to version control
  • Use server-side proxy for Gemini API calls (recommended for production)
  • Implement rate limiting on your backend
  • Sanitize all user inputs before logging to Slack
  • Use HTTPS for all deployments
  • Implement CORS restrictions

Performance Optimization

  • Minify CSS and JavaScript files
  • Use CDN for static assets
  • Enable gzip/brotli compression
  • Lazy load AI handler if not immediately needed
  • Cache font files locally

Customization

Changing Colors

Edit CSS variables in terminal.css:

:root {
  --terminal-bg: #0a0a0a;       /* Background color */
  --terminal-green: #00ff41;     /* Primary text color */
  --terminal-amber: #ffb000;     /* Accent color */
  --terminal-glow: 0 0 5px currentColor;
  --scanline-opacity: 0.05;
}

Customizing Content

Edit config.js to change:

  • ASCII art header
  • Welcome message
  • Command responses
  • AI system prompt
  • Professional information

Adding New Commands

Add new commands in config.js:

commands: {
  mycommand: {
    description: 'My custom command',
    response: `
      <span class="section-header">My Custom Command</span>
      This is my custom response!
    `.trim(),
  },
}

Then handle it in terminal.js processCommand() method.
